Jellyseerr Search Trigger Settings

This plugin triggers Sonarr/Radarr searches when issues are reported via the Plethorafin Android TV app.

When enabled, reporting an issue will trigger a search in Sonarr/Radarr.
Search behavior:
  • Single episode reported = No search (just reports the issue)
  • Whole season reported = Search that season only
  • Whole show reported = Search all episodes

Sonarr Configuration

The URL of your Sonarr instance. Use internal Docker hostname for best performance.
Your Sonarr API key (found in Sonarr → Settings → General).

Radarr Configuration

The URL of your Radarr instance. Use internal Docker hostname for best performance.
Your Radarr API key (found in Radarr → Settings → General).
